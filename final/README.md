# Final

This section is for the second half of the course: in-class code, lab tasks, assignments, and revision material.

## Organize Materials

```text
final/
  code/          Small, runnable examples grouped by week or topic
  labs/          One folder per lab, containing its task and work
  assignments/   One folder per assignment, with the brief and submission
  review/        Notes, practice questions, and exam preparation
```

Use names such as `week-08-fetch-api/`, `lab-05-client-routing/`, and `assignment-03/`. Include each lab or assignment's goal and requirements, along with setup and run instructions for runnable work.

Keep course projects in the separate [`projects/`](../projects/README.md) folder at the repository root.

No syllabus or lab list has been added yet; create topics here as they are confirmed in class.
