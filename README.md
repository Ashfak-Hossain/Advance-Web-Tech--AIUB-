## Running the Examples

The current examples use TypeScript syntax supported directly by recent Node.js versions. From the repository root, run a file with:

```bash
node midterm/code/02_lab/type.ts
node midterm/code/02_lab/promise.ts
```

Each substantial lab, assignment, or project includes its own README with learning objectives and run instructions.

## Repository Guidelines

- Keep source code readable and focused on the topic being demonstrated.
- Use descriptive folder and file names.
- Document setup or execution steps beside each runnable exercise.
- Do not commit dependencies, generated output, credentials, or local environment files.
