# Advanced Web Technology

My coursework for the current semester’s Advanced Web Technology class at American International University-Bangladesh (AIUB).

This repository contains class examples, lab work, assignments, projects, and revision notes. Term-based coursework is organized into midterm and final sections, while course projects have their own folder.

## Repository Structure

```text

├── labs/          Lab work

└── review/        Revision notes and practice

final/
├── code/          In-class examples
├── labs/          Lab work
├── assignments/   Assignments
└── review/        Revision notes and practice

projects/           Course projects and documentation
```
